# data/meshes/legs

Add your custom mesh files here. 

For the legs you should provide:

1. A surface mesh in the `.stl` format for the visualization.
2. [Optional] A volume mesh in the `.vtk` format, if you want to use the **tetra model**.
3. [Optional] A `.txt` file with coordinates in the format [x, y, z, qx, qy, qz, qw], if you want to use the **beam and cosserat models**.

The name of the file should match, for example:

1. `blueleg.stl`
2. `blueleg.vtk`
3. `blueleg.txt`
